# 商业模式

## 定价策略

### 免费版
- 所有本地核心功能完整可用
- 无需注册，无需联网
- 适合：个人用户、自己动手配置的开发者

### 付费版（订阅制）
- 购买向导自动化（百炼 / 火山方舟 / 飞书 Bot）
- 配置云同步 + 版本历史
- 社区模板市场（下载 + 发布）
- 多人协作管理

> 定价参考：¥xx/月 或 ¥xxx/年，具体待市场验证后确定。

---

## 收入来源

1. **订阅付费** — 付费功能按月/年订阅
2. **模板市场抽成** — 创作者发布付费模板，平台分成（后期）

ClawPilot **不做 LLM 代理**，不从 API 用量中赚差价。用户始终自带 Key，ClawPilot 不介入运行时流量。

---

## 支付方案

面向国内用户：
- **微信支付** + **支付宝**
- 需要营业执照（个体工商户即可）

暂不考虑 Stripe / 国际支付，等有明确海外需求后再扩展。

---

## 用户认证

- 手机号 + 短信验证码（主要方式）
- 微信扫码登录（降低注册门槛）
- 不做邮箱注册（国内用户使用率低）

---

## 开源策略

**初期闭源，暂不开源。**

理由：
- 独立开发，无品牌积累，开源过早风险大于收益
- 竞争对手可 fork 后凭借更多资源快速超越
- 开源的主要价值（吸引贡献者、社区信任）在早期意义有限

**未来可能开源的条件：**
- 已建立品牌和用户基础
- 开源能带来实质性的社区贡献或生态价值
- 届时考虑 MIT（本地核心）+ 私有（云服务）的 Open Core 模式

---

## 分发渠道

不依赖应用商店冷启动，主动出击精准渠道：

1. **OpenClaw 用户社区** — 官方 Discord、微信群、百炼/火山方舟开发者社区（最精准）
2. **内容营销** — 发布「用 OpenClaw 搭建 XX 团队」教程文章（少数派、V2EX、小红书、即刻）
3. **GitHub Release** — 代码闭源，但 Release 页公开，能被搜索到
4. **KOL 合作** — 找使用 OpenClaw 的创作者演示

目标用户群体小而集中，不需要广撒网。

---

## 竞争护城河

| 优势 | 说明 |
|------|------|
| 先发 | 率先做出产品，占据用户心智 |
| 自动化脚本 | 购买向导 / 飞书配置的选择器维护在后端，竞争对手复制不了维护体系 |
| 模板市场 | 社区内容形成网络效应，越用越多 |
| 持续迭代 | 快速响应 OpenClaw 版本变化 |

开源被 fork 的风险是真实的，但以上护城河是代码之外的竞争优势。
