# 功能规划

## 本地核心功能（免费，无需后端）

### OPC 管理中心
- 读取本地 OpenClaw 配置，列出所有已有团队（OPC）
- 显示当前激活团队
- 一键切换激活团队（修改 openclaw.json + 重启 OpenClaw）
- 新建 / 复制 / 归档团队

### Agent 设计器
- 可视化 Agent 卡片：展示名字、职称、性格、工具列表、所用模型
- 一句话描述 → 调用用户自己的 LLM → 自动生成完整配置（SOUL.md、IDENTITY.md、AGENTS.md 等）
- 团队组织图视图：展示成员结构和汇报关系
- 点击卡片直接编辑：SOUL.md 内容、工具权限、模型选择
- 护栏规则可视化配置（护栏内 / 护栏外 拖拽，而不是手写）

### Provider & 模型管理
- 支持三个 Coding Plan provider：阿里百炼、火山方舟、MiniMax
- API Key 本地安全存储
- 一键测试 API 连通性
- 每个 Agent 可单独切换模型
- 模型能力对比展示（上下文窗口、费用、输入类型）

### 飞书频道绑定
- 可视化路由表：飞书群 / 用户 → 对应 Agent
- 填写群 ID，预览路由结果
- bindings.json5 可视化编辑

### 部署 & 生命周期
- 一键部署：生成配置文件写入 OpenClaw 目录 + 重启进程
- 部署前自动备份当前配置（本地快照）
- 快照历史：支持本地回滚
- 导出配置包：打包为 zip，可分发给他人
- 实时日志：内嵌 OpenClaw 日志流，显示 dispatch、replies、error 事件

## 引导自动化功能（付费）

### 阿里百炼 Coding Plan 购买向导
- 内嵌 Webview 打开阿里云登录页
- 用户自行登录（ClawPilot 不接触账号密码）
- 检测登录成功后自动导航到 Coding Plan 购买页
- 购买完成后自动跳转 API Key 创建页，提取 Key 写入配置

### 火山方舟 Coding Plan 购买向导
- 同上，适配火山方舟控制台流程

### 飞书 Bot 自动配置
- 用户输入：Bot 名字、描述
- 内嵌 Webview 打开飞书开放平台，用户扫码登录
- 自动完成：创建应用、填写名称描述、勾选必要权限、配置 WebSocket 连接、发布应用
- 提取 appId + appSecret 写入 channels.json5

> 自动化脚本（CSS 选择器）维护在后端，App 每日拉取更新，三方平台改版后无需发版即可修复。

## 云端付费功能

### 配置云同步
- OPC 配置多设备同步
- 版本历史：每次部署自动存档，支持云端回滚
- 手动创建命名快照（如「上线前稳定版」）

### 社区模板市场
- 浏览社区分享的团队模板（按行业 / 场景分类）
- 一键导入模板 → 填入自己的信息 → 生成
- 发布自己的团队模板
- 模板评分和收藏

### 多人协作
- 多个成员共同管理同一个 OPC 配置
- 变更记录和审批流程
- 基于角色的编辑权限

## 功能优先级

| 优先级 | 功能 |
|--------|------|
| P0（MVP） | OPC 管理、Agent 设计器、Provider 配置、一键部署、日志查看 |
| P1 | 飞书绑定可视化、本地快照回滚、导出配置包 |
| P2 | 购买向导自动化、飞书 Bot 自动配置 |
| P3 | 云同步、模板市场、多人协作 |
