# 产品路线图

## v0.1 — MVP（本地核心）

**目标：** 能用，替代手写配置文件

- [ ] OpenClaw 安装检测 & 路径识别
- [ ] 读取现有 OPC 配置，展示团队列表
- [ ] 新建团队向导：选 Provider → 填成员信息 → 生成配置文件
- [ ] 一键部署（写入文件 + 重启 OpenClaw）
- [ ] 简单日志查看（尾读 OpenClaw 日志）
- [ ] 导出配置包（zip）

- [ ] 飞书绑定可视化配置（路由表）
- [ ] 本地配置快照 & 回滚
- [ ] 模型能力对比展示
