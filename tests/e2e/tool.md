# 工具管理 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。

---

## 基础展示

**工具列表加载**
1. 在 Agent 编辑状态下，工具区域展示当前所有可用工具（内置 + 自定义）
2. 每个工具显示：名称（`display_name`）、分类（`category`）、来源标签（内置 / 本地自定义）
3. 内置工具带勾选框，默认按数据库 `created_at` 倒序排列
4. 列表为空时显示「暂无工具」占位文字，不崩溃

---

## 工具 CRUD

**创建自定义工具**
1. 进入工具管理入口，点击「新建工具」按钮
2. 填写内部名称（`name`）、显示名称（`display_name`），分类留空默认为 `general`
3. 提交后工具出现在列表中，标签显示「本地」
4. 工具名称重复时提示「工具名称已存在」，创建被阻止
5. `display_name` 为空时，提示必填错误，保存被阻止

**查看工具详情**
1. 点击某个工具条目，右侧或弹窗展示详细信息：名称、显示名称、描述、分类
2. 内置工具（`is_local = 0`）不显示「删除」按钮，或按钮禁用

**删除自定义工具**
1. 选中一个本地自定义工具（`is_local = 1`），点击「删除」
2. 无额外确认，直接从列表消失
3. 若 Agent 已勾选该工具，进入该 Agent 编辑，工具勾选列表中该项显示「已移除」或不再出现（不崩溃）

---

## 在 Agent 中使用工具

**勾选内置工具**
1. 进入 Agent 编辑状态，工具列表显示所有内置工具（含勾选框）
2. 勾选若干工具后保存，再次进入该 Agent，勾选状态保持

**取消勾选**
1. 取消已勾选工具后保存
2. 再次进入该 Agent，该工具不再显示为勾选状态

**添加自定义工具标签**
1. 编辑状态下，在自定义工具输入框输入工具名称，按 Enter 添加
2. 工具以浅紫色标签形式出现，标签内容为输入的名称
3. 点击标签右侧「×」移除
4. 保存后再次进入，自定义工具标签列表保持

---

## 边界情况

- 工具名称含空格或特殊字符时，`name` 字段的唯一性约束正常触发
- 内置工具数量为 0 时，工具勾选区显示空状态，不崩溃
- 自定义工具标签与内置工具同名时，两者独立存在，无冲突
- 快速连续点击「新建」两次，不产生两条记录（按钮应有防重复提交保护）
