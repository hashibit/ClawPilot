# 概览 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。

---

## 进程状态卡片

**停止状态**
1. 进入 `#/overview`，OpenClaw 进程未运行时：
   - 状态指示点为灰色
   - 状态文字显示「已停止」或类似文本
   - 仅显示「Start」按钮（绿色）
2. 点击「Start」按钮，按钮禁用（procLoading=true）
3. 约 1 秒后自动拉取进程状态，按钮恢复可用
4. 进程启动成功后：状态点变为绿色脉冲，显示 PID 和运行时间

**运行状态**
1. OpenClaw 运行中时：
   - 状态点为绿色脉冲
   - 显示 PID 和已运行时长（格式：`Xm Ys` / `Xh Ym`）
   - 显示「Reload」和「Stop」两个按钮

**重载进程**
1. 点击「Reload」，按钮禁用
2. 约 1 秒后进程状态刷新，运行时间重置
3. PID 可能变化

**停止进程**
1. 点击「Stop」（红色），按钮禁用
2. 约 1 秒后状态点变为灰色，PID 消失，显示「Start」按钮

**运行时间格式化**
- 运行时间 < 60 秒：显示 `Xs`
- 60 秒 ≤ 运行时间 < 1 小时：显示 `Xm Ys`
- 运行时间 ≥ 1 小时：显示 `Xh Ym`

## 统计数据卡片

1. 页面加载后 2×2 网格显示四张统计卡片：
   - 团队数（OPC 总数）
   - 智能体数
   - 频道数
   - 今日消息数
2. 每张卡片显示大数值 + 标签 + 趋势箭头（↑/↓）和百分比
3. 切换 OPC（通过其他页面操作）后刷新回概览，统计数据应更新

---

## 消息趋势卡片

1. 显示今日消息总量（大数值）
2. 趋势百分比和方向（↑ 上升 / ↓ 下降）
3. 趋势条（进度条样式）按当日消息量与最大值比例填充

---

## OPC 消息量对比

1. 水平条形图按各 OPC 消息量降序排列
2. 每行显示：OPC 名称 + 彩色进度条 + 具体消息数数值
3. 消息量最多的 OPC 进度条填充 100%，其余按比例缩短
4. 无 OPC 时显示「暂无数据」占位文字

---

## 运行中的 OPC

1. 有运行中 OPC 时，底部列表显示：Avatar + OPC 名称 + 消息趋势小条 + 消息数
2. 无运行中 OPC 时，该区域不显示或显示空状态

---

## 自动轮询

1. 进程状态卡片每 5 秒自动刷新一次（无需用户操作）
2. 进程状态变化后（如被其他工具停止），概览页面在下次轮询时自动反映最新状态

---

## 边界情况

- 进程操作（Start/Stop/Reload）失败时显示 alert 弹窗，包含错误信息
- 统计数据加载失败时，对应卡片数值显示 `0`，不崩溃
- OPC 数量为 0 时，消息趋势条不出现除以零的错误
- 进程操作后按钮有防重复点击保护（procLoading 期间禁用）
