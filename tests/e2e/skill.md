# 技能市场 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。
> 涉及从 ClawHub / Lightmake 拉取远程技能的场景需要网络连通。

---

## 基础展示

**技能列表加载**
1. 进入 `#/agents`，在编辑状态下点击技能区「+ 添加」按钮，打开 Skill Modal
2. Modal 展示技能列表，每条记录显示：名称、描述（若有）、来源标签（本地 / ClawHub / Lightmake）
3. 已安装技能（`is_installed = 1`）显示在列表顶部，带「已安装」绿色徽章
4. 已安装技能可直接勾选；未安装的远程技能显示「安装」按钮

**空状态**
- 数据库无任何技能时，列表显示「暂无技能」占位文字，不崩溃
- 搜索无结果时，显示「未找到匹配技能」，不显示旧数据

---

## 本地技能 CRUD

**创建本地技能**
1. 在技能管理页（或 Skill Modal 内「新建」入口），填写技能名称（`name`）、显示名称（`display_name`）
2. 分类（`category`）留空时默认填入 `general`
3. 提交后技能出现在列表中，标签显示「本地」
4. 技能名称重复时提示「技能名称已存在」，创建被阻止

**删除本地技能**
1. 选中一个本地技能（`is_local = 1`），点击「删除」
2. 技能从列表消失；若该技能有安装目录（`install_path`），对应目录同时被清理
3. 非本地技能（来自 ClawHub）不显示「删除」按钮，或点击无效

---

## 从 ClawHub 同步

**同步技能列表**
1. 在技能市场页点击「同步」按钮
2. 按钮显示「同步中…」禁用状态
3. 成功后提示「已同步 N 个技能」，列表更新，远程技能显示来源「ClawHub」
4. 已安装的技能同步后 `is_installed` 状态保持不变

**ClawHub 离线时**
1. 断网情况下点击「同步」
2. 按钮恢复可用，显示红色错误提示（如「ClawHub 返回 502」），列表保持原状

---

## 搜索技能

**搜索 ClawHub（默认来源）**
1. Skill Modal 搜索框输入关键词（如 `commit`），防抖 400ms 后自动发起搜索
2. 结果列表展示匹配技能：slug、名称、描述、作者、下载数 / Stars、版本号
3. 输入空字符串或清空搜索框：不发起请求，显示已有本地/已安装列表

**搜索 Lightmake**
1. 来源切换为「Lightmake」，输入关键词搜索
2. 结果来自 `lightmake.site/api` 接口，格式与 ClawHub 结果一致
3. 两个来源切换后各自独立保存搜索结果，切换时不清空

**搜索无网络**
1. 离线时在 Skill Modal 输入关键词
2. 远程搜索失败后显示红色提示「搜索失败，请检查网络」，已安装技能列表不受影响

---

## 安装技能

**一键安装（来自 ClawHub）**
1. 在 Skill Modal 的搜索结果中，找到一个未安装的技能，点击「安装」
2. 按钮显示「安装中…」禁用状态（防重复点击）
3. 服务端从 `{LIGHTMAKE_BASE}/skills/{slug}/download` 下载 zip，解压到 `skills/{slug}/`
4. 安装成功后：
   - 该技能列表行显示「已安装」绿色徽章
   - 「安装」按钮变为「已安装」或隐藏
   - 刷新 Modal，该技能出现在已安装列表顶部，可勾选
5. 若 zip 内只有一层子目录（常见打包格式），内容自动提升到 `skills/{slug}/` 根目录（不嵌套）

**安装失败**
1. 下载 URL 不可达（如 slug 不存在）时，按钮恢复可用，显示「安装失败：下载失败 404: {slug}」
2. 列表中该技能保持「未安装」状态

**重复安装**
1. 对已安装技能点击「安装」
2. 服务端先清除旧目录，再重新解压（幂等）
3. 安装完成后技能状态正常，无报错

---

## 卸载技能

**卸载 ClawHub 技能**
1. 在已安装技能列表中，选中一个来自 ClawHub 的技能，点击「卸载」
2. 无额外确认，直接执行
3. 成功后：
   - `skills/{slug}/` 目录被删除
   - 技能 `is_installed` 变为 0，`install_path` 清空
   - 列表中该技能从「已安装」区移至「可安装」区，显示「安装」按钮
4. 若 Agent 的 `enabled_skills` 中引用了该技能，重新进入该 Agent，技能显示为「未安装」状态（不崩溃）

**卸载本地技能**
1. 卸载本地创建的技能（`is_local = 1`）
2. 数据库记录同时删除（与 ClawHub 技能只清安装状态不同）
3. 列表中该技能完全消失

---

## 在 Agent 中使用技能

**勾选已安装技能**
1. 在 Agent 编辑状态下，打开 Skill Modal
2. 仅已安装技能（`is_installed = 1`）可直接勾选
3. 勾选若干技能后点击「确认」，技能名称出现在 Agent 技能列表
4. 保存 Agent 后刷新页面，技能列表保持

**从 Modal 安装并立即勾选**
1. 搜索到一个未安装技能，点击「安装」，等待完成
2. 安装完成后该技能自动变为可勾选状态
3. 勾选后点「确认」，流程与已安装技能相同

**移除 Agent 中的技能**
1. 在 Agent 技能列表中，点击某个技能右侧「×」
2. 技能从列表消失；保存后刷新确认移除持久化
3. 技能从 Agent 移除不影响其安装状态（技能文件仍在）

---

## 边界情况

- slug 包含特殊字符（如 `-`、`_`）时，目录名和数据库记录正常处理
- 同时打开两个 Agent 的 Skill Modal（不同 Tab）安装同一技能，第二次安装幂等不报错
- Modal 关闭后再打开，搜索框清空，列表重置为初始状态
- 技能数量超过 50 个时，列表可正常滚动，不截断
