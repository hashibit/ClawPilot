## 渠道配置

### 飞书渠道

**首次配置**
1. 进入 `#/bindings`，选择飞书 Tab
2. 点击「配置」或「编辑配置」进入编辑态
3. 填写 App ID 和 App Secret，点击「保存」
4. 状态指示灯变为绿色，Tab 标题显示「已配置」
5. 再次进入，App ID 脱敏显示（前 8 字符 + `***`），App Secret 显示为 `已配置`

**测试连接**
1. 配置已保存的情况下，点击「测试连接」按钮
2. 按钮显示「测试中…」禁用状态
3. 成功：绿色「✓ 连接成功」提示；失败：红色错误信息

**重新配置**
1. 已配置状态下点击「重新配置」
2. 字段变为可编辑，App ID 和 Secret 清空（需重新填写）
3. 修改后保存，配置更新

### 钉钉渠道

1. 切换至钉钉 Tab，类似飞书流程
2. 填写钉钉对应凭证（App Key、App Secret 等），保存后显示「已配置」
3. 非编辑态密钥类字段以密码类型显示（`●●●●●●●`）

### Slack 渠道

1. 切换至 Slack Tab，类似飞书流程
2. 填写 Bot Token 等字段，保存后显示「已配置」

### 渠道切换注意事项

- 切换渠道 Tab（如从飞书切到钉钉）时，不保留前一 Tab 的未保存输入
- 各 Tab 独立维护编辑/非编辑状态

## 群组绑定 CRUD

**创建绑定**
1. 在左侧群组列表底部点击「+」按钮
2. 列表出现「新群组」占位符，显示「未保存」标签
3. 右侧面板展开编辑区：填写群组名称、群组 ID，选择关联 Agent
4. 触发模式默认为「MENTION」，启用 Toggle 默认开启
5. 点击「保存」，临时条目变为正式记录，「未保存」消失
6. 若群组 ID 为空：显示必填错误提示，保存被阻止

**编辑绑定**
1. 点击某条绑定记录，右侧面板展示当前配置
2. 点击「编辑」进入编辑态
3. 修改群组名称、关联 Agent 或触发模式
4. 点击「保存」：列表中该条记录同步更新
5. 点击「取消」：面板恢复为保存前的值

**删除绑定**
1. 点击某条绑定右侧的「删除」按钮
2. 无额外确认，直接从列表消失
3. 若已选中该条记录，右侧面板清空

## 绑定状态管理

**切换启用/禁用**
1. 在绑定详情面板中，点击「启用」Toggle
2. 前端列表即时更新状态标签：「已绑定」→「已禁用」
3. 刷新页面后状态保持

**触发模式**
1. 编辑绑定时，触发模式可选「MENTION」或「ALL」
2. 选择「ALL」后保存，再次进入该绑定，触发模式保持

---

## 关联 Agent 同步

1. 在绑定详情中将关联 Agent 从 A 改为 B，保存
2. 群组列表中该条记录的 Agent 名称同步更新为 B
3. 若 Agent B 被删除（在 `#/agents` 中），重新进入该绑定，Agent 字段显示「未指定」

---

## 边界情况

- 无任何渠道配置时，群组列表显示空状态提示
- 切换 OPC 时，群组绑定列表重置，右侧面板清空
- Bailian URL 与 API Key 前缀不匹配时，保存按钮下方显示黄色警告
- 飞书 App ID 长度 < 3 时保存被阻止，显示格式错误提示
