# 模型提供商管理 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。

---

## 提供商配置

**首次配置（百炼）**
1. 进入 `#/providers`，显示百炼提供商卡片，状态标签为「未配置」
2. 点击「编辑配置」进入编辑态
3. 点击「Coding Plan」快捷按钮，自动填充 Coding Plan 格式 Base URL
4. 填写 API Key（`sk-sp-` 前缀格式），验证提示应显示格式正确
5. 点击「保存」，卡片状态标签变为「Coding Plan」

**按量计费配置**
1. 点击「编辑配置」进入编辑态
2. 点击「按量计费」快捷按钮，自动填充按量计费 Base URL
3. 填写 API Key（`sk-` 前缀格式），验证提示显示格式正确
4. 保存后状态标签变为「已配置」

**重新配置**
1. 已配置状态下点击「编辑配置」
2. Base URL 和 API Key 字段变为可编辑状态
3. API Key 字段显示掩码（前 8 字符 + `***`）
4. 修改保存后配置更新，测试结果清除

## 格式验证

**API Key 前缀校验**
- Key 前缀为 `sk-sp-` 且 URL 为 Coding Plan 格式：验证通过（无警告）
- Key 前缀为 `sk-` 且 URL 为按量计费格式：验证通过（无警告）
- Key 前缀为 `sk-sp-` 但 URL 为按量计费格式：显示黄色「格式不匹配」警告，保存按钮禁用
- Key 前缀为 `sk-` 但 URL 为 Coding Plan 格式：显示黄色警告，保存按钮禁用
- Key 为空时：显示必填错误，保存按钮禁用
- Base URL 不是 http/https 开头时：显示格式错误，保存按钮禁用

**URL 变更提示**
- 修改 Base URL 时，卡片显示紫色提示，说明将测试的接口格式（OpenAI / Anthropic）

## 测试连接

**成功场景**
1. 已配置 API Key 和 Base URL 的情况下，点击「测试连接」
2. 按钮显示「测试中…」禁用状态
3. 成功：卡片内显示绿色「✓ 连接成功」徽章 + 延迟信息

**失败场景**
1. 使用无效 API Key 点击「测试连接」
2. 卡片内显示红色「✗ 连接失败」徽章 + 错误详情文本

**未配置时禁用**
1. Base URL 或 API Key 为空时，「测试连接」按钮禁用，鼠标悬停显示提示

## 模型列表

**查看模型**
1. 提供商已配置后，卡片下方显示模型列表表格
2. 列表显示：模型名、上下文窗口（格式：`128K`、`1M`）、输入类型、能力标签
3. 具有 Vision 能力的模型显示「Vision」标签
4. 支持 Streaming 的模型显示「Streaming」标签

**数值格式化**
- 上下文窗口超过 1,000,000 tokens 时显示为「XM」
- 超过 1,000 tokens 时显示为「XK」
- 模型列表为空时显示空状态，不显示「0 models」

---

## 边界情况

- 编辑配置时先清除之前的测试结果（成功/失败徽章消失）
- 保存成功后自动退出编辑态
- 保存失败时保持编辑态并显示错误 toast
- 模型列表加载中显示加载占位符，不展示旧数据
