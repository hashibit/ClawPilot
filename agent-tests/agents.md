# Agent 管理 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。

---

## CRUD

**创建 Agent**
1. 进入 `#/agents`，在 COL2 选中某个 OPC
2. 点击 COL3 底部「创建 Agent」按钮，弹出创建表单
3. 不填写必填字段直接提交：出现错误提示，提交被阻止
4. 填写显示名称（内部名称自动由 displayName slug 化生成）
5. 提交后 COL3 列表出现新 Agent 小卡片，自动分配颜色（不与同 OPC 其他 Agent 重复）

**编辑 Agent 基本信息**
1. 选中某个 Agent，点击 Toolbar 上的「编辑」按钮
2. 面板切换为编辑态，可修改：显示名称、内部名称、岗位名称、描述
3. 修改显示名称后，Toolbar 标题同步更新
4. 点击「保存」：面板切换回查看态，列表中该 Agent 名称同步更新
5. 点击「取消」：表单恢复为**上次保存的值**（服务器当前值），列表无变化（注：取消不能撤销已提交的保存）

**删除 Agent**
1. 选中某个普通 Agent，点击「删除」
2. 出现确认对话框；若是默认 Agent，对话框显示特殊警告
3. 确认后列表消失，关联的 Bindings 也应级联清除（可在 `#/bindings` 验证）
4. 自动切换到默认 Agent 或列表首个

## 模型与工具配置

**配置模型**
1. 编辑状态下点击「模型」下拉
2. 下拉列表按提供商分组，可选自定义模型（若存在）
3. 选择某个模型后保存，再次进入该 Agent，模型选择保持

**配置内置工具**
1. 编辑状态下，工具列表显示 10 个预设工具，带勾选框
2. 勾选或取消勾选若干工具后保存
3. 再次进入该 Agent，工具勾选状态保持

**添加自定义工具**
1. 编辑状态下，在自定义工具输入框输入工具名称，按 Enter 添加
2. 工具以浅紫色标签形式出现在列表
3. 点击标签上的 × 移除该工具
4. 保存后再次进入，自定义工具列表保持

## 人格文档编辑

**切换文档 Tab**
1. 底部显示 7 个文档 Tab：SOUL、IDENTITY、AGENTS、USER、MEMORY、HEARTBEAT、TOOLS
2. 点击各 Tab 切换内容区，每个 Tab 独立显示对应文档内容

**编辑并保存文档**
1. 选中 SOUL Tab，修改文本内容
2. 点击保存（或 Toolbar 保存按钮）
3. 刷新页面后再次进入该 Agent，SOUL 内容保持修改后的值

---

## 技能配置

**添加技能**
1. 编辑状态下，点击技能区「+ 添加」按钮，打开 Skill Modal
2. Modal 展示已安装技能列表；搜索框输入关键词（防抖 400ms），过滤结果
3. 勾选某个技能，点击「确认」，技能出现在 Agent 技能列表

**从 ClawHub 安装技能**
1. Skill Modal 中搜索远程技能名称
2. ClawHub 返回结果后显示可安装的技能
3. 点击「安装」，等待完成后该技能进入已安装列表
4. 刷新 Modal，已安装技能可勾选启用

**移除技能**
1. 在 Agent 技能列表中，点击某个技能右侧的移除按钮
2. 技能从列表消失，保存后刷新页面确认移除持久化

---

## 护栏规则

1. 编辑状态下，护栏区分「允许」和「禁止」两个 TagInput
2. 在「禁止」输入框输入规则文本，按 Enter 或逗号分隔添加
3. 标签出现后可点击 × 移除
4. 保存后再次进入该 Agent，护栏规则保持

---

## 拖拽排序（需人工）

1. COL3 中按住某个 Agent 卡片并拖拽到不同位置
2. 拖拽过程中列表实时重排
3. 释放后 Agent 新顺序持久化，刷新页面顺序保持

---

## 设置默认 Agent

1. 在非编辑模式下选中某个非默认 Agent
2. 点击「设为默认」按钮
3. 该 Agent 在列表中显示蓝点和较大尺寸
4. 原默认 Agent 恢复正常样式

---

## AI 快速生成

1. 编辑状态下，在 AI 生成输入框中输入描述（如「一个机器学习专家」）
2. 点击「生成」，等待响应
3. 自动填充：显示名称、内部名称、岗位名称、描述、personality
4. 7 个文档 Tab（SOUL 等）内容自动生成并保存
5. 生成完成后自动跳转到 SOUL Tab，输入框清空

---

## 测试对话（Chat Drawer）

**已保存 Agent 的对话**
1. 选中已保存的 Agent（有 SOUL 内容），点击「测试对话」
2. 右侧 Drawer 展开（400px），显示对话窗口
3. 输入消息，按 Enter 发送（Shift+Enter 换行）
4. 收到 AI 回复，对话历史正确显示多轮内容
5. 再次发送消息，历史上下文保持

**SOUL 为空时的提示**
1. 选中 SOUL 文档为空的 Agent，点击「测试对话」
2. Drawer 内显示「请填充 SOUL 内容」警告，无法发送消息

---

## 边界情况

- 新建 Agent 未保存时切换 OPC：提示「请先保存」，切换被阻止
- 同 OPC 内颜色自动分配不重复；若颜色池耗尽则循环复用
- 模型列表为空时下拉仅显示空选项，不崩溃
- ClawHub 离线时 Skill Modal 远程搜索返回空列表，不影响已安装技能展示
- 拖拽排序失败时前端排序回滚，UI 恢复原始顺序
