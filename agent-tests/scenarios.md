# ClawPilot UI 测试场景（agent-browser）

> 本文档是 **agent-browser 测试脚本**，以自然语言描述操作步骤与预期行为，
> 由 Claude Code 调用 `agent-browser` skill 驾驶浏览器执行，或由人工逐项验证。
> pass/fail 由 AI 根据截图和页面状态判断，无代码断言。

---

## 一、基础页面加载

- 启动开发服务器后访问首页，确认侧边栏和内容区正常渲染，无报错
- 依次点击侧边栏所有导航项（Overview / OPC / Agents / Bindings / Providers / Office / Deploy / Logs / Settings），确认每个页面正常加载、URL hash 对应正确

---

## 二、OPC 管理

**创建 OPC**
1. 进入 `#/opc` 页面
2. 点击创建按钮，弹出创建 Modal
3. 填写内部名称和显示名称，选择头像颜色
4. 点击提交，Modal 关闭，列表出现新建的 OPC 卡片

**编辑 OPC**
1. 点击某个 OPC 卡片进入编辑界面
2. 修改显示名称或描述，保存后列表卡片文字同步更新

**删除 OPC**
1. 对非当前激活的 OPC 执行删除
2. 确认 Modal 出现，确认后列表中该 OPC 消失

**快照管理**
1. 对 OPC 创建快照，列表出现新快照记录
2. 恢复某快照，OPC 配置恢复到快照时的状态
3. 导出快照为 JSON 文件并验证内容格式正确
4. 导入快照文件，数据正确加载

---

## 三、Agent 管理

**创建 Agent**
1. 进入 `#/agents`，点击创建按钮
2. 填写 Agent 名称和显示名称，保存后左侧列表出现新 Agent

**编辑 Agent**
1. 选中一个 Agent，在右侧面板编辑 SOUL / IDENTITY 等文档
2. 保存后重新进入该 Agent，内容保持

**配置工具**
1. 在 Agent 工具列表中添加或移除工具
2. 保存后再次进入，工具配置保持

**拖拽排序（需人工）**
1. 在 Agent 列表中拖拽调整顺序
2. 释放后顺序自动保存，刷新页面顺序保持

**删除 Agent**
1. 删除一个 Agent，左侧列表消失，关联的 Bindings 也应级联清除

---

## 四、渠道与绑定

**飞书渠道配置**
1. 进入 `#/bindings`，选择飞书 Tab
2. 填写 App ID 和 App Secret，保存后显示「已配置」状态
3. 再次进入，配置内容保持（密钥字段脱敏显示）

**钉钉 / Slack 渠道**
1. 类似飞书流程，填写对应凭证并保存

**群组绑定**
1. 在渠道已配置的前提下，创建一条 Binding，关联 Agent 和群组 ID
2. 切换 Binding 的启用/禁用状态，保存后状态保持

---

## 五、模型提供商

**配置 API Key**
1. 进入 `#/providers`，选择一个提供商（如 OpenAI）
2. 填写 API Key，保存后提供商卡片显示「已配置」标记
3. 再次进入，Key 字段脱敏显示

**刷新模型列表**
1. 点击「测试连接 / 刷新模型」按钮
2. 等待响应，成功时模型列表更新；失败时显示错误提示

---

## 六、Office 管理

> 详细场景见 [`office.md`](./office.md)，涵盖 CRUD、地址模式切换、门禁认证、物业安装、Daemon 健康检查、部署信息展示，共 25 个测试点。

---

## 七、部署流程

**完整部署**
1. 进入 `#/deploy`，选择一个 OPC 和一个 Office
2. 点击部署，进度条推进，最终显示「部署成功」

**撤销部署**
1. 对已部署的 OPC 点击撤销部署
2. 确认后状态变更为「未部署」

**部署包下载（需人工）**
1. 触发部署后下载生成的配置包
2. 解压验证文件结构与 OPC 配置一致

---

## 八、日志

1. 进入 `#/logs`，确认实时日志流正常显示
2. 按日志级别（DEBUG / INFO / WARN / ERROR）过滤，列表内容对应筛选
3. 按组件名称过滤，确认过滤结果正确
4. 清除旧日志后列表为空或仅剩新日志

---

## 九、网络异常处理

1. 在 Server 未启动的情况下访问任意数据页面，页面应显示错误提示或空状态，不崩溃
2. 发起需要网络的操作（如创建 OPC）时网络中断，应有友好的错误提示，不丢失已填写数据

---

## 十、表单验证

**OPC 创建验证**
1. 打开创建 Modal，不填写任何字段直接提交
2. 内部名称和显示名称字段应出现必填错误提示，Modal 不关闭

**Agent 创建验证**
1. 同上，必填字段为空时提交应被拦截

## 远程主机测试（OrbStack）

部分场景（Office 远程模式、SSH 连通检测、安装物业到远程主机）需要真实的远程主机。
可用 **OrbStack** 在本机快速创建 Linux VM：

```bash
orb list                          # 查看现有 VM，如 clawpilot-test (192.168.139.170)
orb create ubuntu clawpilot-test  # 如需新建
```

详细配置步骤见 [`office.md`](./office.md) 的「测试环境准备」章节。

**已验证的 VM 规格**：OrbStack Ubuntu 25.04 arm64，`clawpilot-test`，IP `192.168.139.170`
