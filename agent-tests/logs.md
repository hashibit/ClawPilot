# 日志 — agent-browser 测试场景

> 由 Claude Code 调用 `agent-browser` skill 执行，或人工逐项验证。

---

## 基础展示

**日志流加载**
1. 进入 `#/logs`，确认日志流容器正常渲染
2. Toolbar 显示「实时」绿色脉冲徽章，表示自动拉取激活中
3. 每条日志显示：时间戳、级别标签（INFO / WARN / ERROR / DEBUG / SYSTEM）、组件名、消息
4. 若日志含频道字段，该字段显示在组件名后

**自动滚动**
1. 新日志到达时，日志容器自动滚动到底部
2. 手动向上滚动后，停止自动滚动（不强制拉回底部）

---

## 实时更新

**轮询行为**
1. 页面打开后每 3 秒自动调用一次日志接口
2. 新日志追加到列表末尾，时间戳有序
3. 切换到其他页面后再切回，轮询重新启动

---

## 清空与恢复

**清空日志**
1. 点击 Toolbar 上的「清空」按钮
2. 日志容器变为空，显示「已清空」提示文字
3. 新到达的日志不再显示（cleared 状态）
4. 轮询仍在运行，但结果被忽略

**恢复日志**
1. 清空状态下点击「恢复」按钮
2. 开始重新接收并显示新日志
3. 旧日志不会恢复（仅展示清空后产生的日志）

---

## 过滤功能

**按日志级别过滤（复选框组）**
1. 默认所有级别选中
2. 取消勾选「DEBUG」：日志列表中 DEBUG 条目消失
3. 只保留「ERROR」勾选：仅显示错误级别日志
4. 重新全部勾选：所有级别日志恢复显示

**按级别过滤（下拉）**
1. 级别下拉默认为「全部」
2. 选择「WARN」：列表只显示 WARN 级别
3. 选择「全部」：恢复显示所有级别
4. 下拉与复选框独立工作（互不干扰）

**按组件名过滤**
1. 在组件过滤输入框输入组件名关键词（如 `feishu`）
2. 列表实时更新，只显示组件名包含该关键词的日志（大小写不敏感）
3. 清空输入框后，恢复显示所有组件的日志

**统计数值**
1. 筛选条件变化后，右侧面板底部统计数值随之更新
2. 统计显示当前过滤后的日志条数

---

## 边界情况

- 日志加载失败时显示错误 toast，列表保持原状（不清空）
- 过滤结果为零时显示「无匹配日志」空状态文字，不崩溃
- 日志量较大时列表使用固定高度容器，页面整体不随日志增多而变高
- 时间戳按本地时区格式化显示
