


ClawPilot — 产品结构说明

  一、产品定位

  ClawPilot 是一个 AI 团队可视化配置管理工具。用户通过图形界面管理 OPC（OpenClaw 团队配置），包括创建公司（OPC
  团队）、配置智能体（Agent）、设置模型提供商、管理部署目标（办公室），最终一键部署到远程服务器。

  目标用户：需要管理多个 AI Agent 团队的运营人员，而非终端用户。

  设计语言：深色主题，暗色背景 + 紫色强调色，类似 VS Code / Linear 的风格。

  │ 3   │ 模型管理   │ LLM 提供商 + 模型管理        │ 全局     │
  ├─────┼────────────┼──────────────────────────────┼──────────┤
  │ 4   │ 办公室管理 │ 部署目标主机列表             │ 全局     │

  公司空间导航（Company-Space Sidebar）

  从公司列表点击"进入公司"后，侧边栏切换为 3 个入口，顶部显示当前公司名称：

  ┌─────┬────────────┬───────────────────────────┐
  │  #  │    页面    │           说明            │
  ├─────┼────────────┼───────────────────────────┤

  ├─────┼────────────┼───────────────────────────┤

  └─────┴────────────┴───────────────────────────┘

  点击"返回首页"退出公司空间，切回全局导航。

  ---
  三、各页面功能详解

  1. 数据概览 (Overview)

  作用：全局运营大盘。

  内容区：
  - 核心指标卡片：公司总数、智能体总数、飞书频道数、今日消息数 + 较昨日增长率
  - 消息趋势：今日消息总数 + 进度条可视化
  - 各公司消息量：按公司分组的横向柱状图，带颜色区分
  - 运行中公司：显示已部署且运行中的公司列表

  交互：纯展示，无编辑操作。

  ---
  2. 公司列表 (Companies)

  作用：管理 OPC 团队（子公司）。

  Toolbar：搜索框 + "创建公司"按钮

  公司卡片（Grid 布局，每卡片含）：
  - 头像（首字母 + 颜色）、公司名称、运行状态（运行中/已停止）
  - 智能体数量、飞书频道数量
  - 操作按钮："进入公司"（进入公司空间）、"删除"

  创建弹窗：填写内部标识（英文）+ 显示名称（中文）

  交互：
  - 搜索实时过滤
  - "进入公司" → 导航栏切换为公司空间导航，跳转到智能体管理页
  - 删除需确认

  ---
  3. 模型管理 (Providers)

  作用：配置 LLM API 提供商和可用模型。

  布局：左右分栏（左侧列表 + 右侧详情）

  左侧列表：
  - 每个提供商卡片：头像、名称、API 协议标签（OpenAI/Anthropic/Gemini）、连接状态
  - 底部"添加"按钮

  右侧详情（查看模式）：
  - 提供商信息：名称、协议、Base URL、API Key（掩码显示）、连接状态、最后测试时间
  - 测试连接按钮、编辑、删除
  - 模型列表表格：model_id、模型名、上下文窗口、input_types、vision 支持、编辑/删除

  编辑/创建模式：
  - Base URL 输入后自动识别提供商（Auto-suggest）
  - 表单：Base URL、名称、协议选择、API Key
  - 模型表格可编辑/添加/删除行

  交互：
  - 点击左侧切换选中提供商
  - 创建新提供商时输入 Base URL 自动推断名称和协议
  - "测试连接"验证 API Key 有效性
  - 模型表支持内联编辑

  ---
  4. 办公室管理 (Office)

  作用：管理部署目标主机（本地或远程服务器），安装和管理 OpenClaw 环境。

  布局：左右分栏（左侧列表 + 右侧详情）

  左侧列表：
  - 每个办公室：接待员头像（可自定义）、名称、装修等级、地址
  - 底部"添加"按钮

  右侧详情区（分段展示）：

  基本信息：
  - 名称输入
  - 接待员头像选择器（点击弹出预设画廊，hover 放大预览）
  - 地址：本机/远程切换按钮 + IP 输入框
  - 远程模式下展开门禁设置：用户名、认证方式（密码/SSH 密钥）
  - 装修等级选择器（HIGH/MEDIUM/LOW）
  - 备注文本域

  物业信息：
  - Daemon 状态：在线/离线/未安装 + 版本号
  - OpenClaw 状态：运行中/未安装 + 版本号
  - 操作：刷新健康检查、"安装物业"

  当前部署：
  - 显示当前部署到该办公室的公司
  - 部署历史列表（时间线，含撤销标记）

  安装物业弹窗：
  - 步骤指示器：SSH 检查 → OpenClaw → Daemon
  - 实时日志输出区域（Terminal 风格）
  - 停止/关闭按钮

  交互：
  - 左侧选择办公室
  - 远程模式下可"测试连接"验证 SSH
  - "安装物业"打开模态弹窗，实时显示安装进度
  - Daemon 在线时可刷新健康状态

  ---
  5. 运行日志 (Logs)

  作用：操作审计日志。

  布局：列表形式，按时间倒序展示日志条目。

  内容：操作类型、操作者、时间、详情。

  ---
  6. 实时活动 (Activities)

  作用：消息活动实时监控。

  布局：实时消息流展示。

  ---
  7. 设置 (Settings)

  作用：全局系统配置。

  内容：opc_root 路径设置等全局参数。

  ---
  8. 智能体管理 (Agents) — 公司空间

  作用：配置公司下所有 AI 智能体（核心页面，功能最多）。

  布局：上中下三段

  Agent 条（顶部横向滚动条）：
  - 每个 Agent 显示头像（带颜色渐变）+ 名称，选中高亮
  - 默认 Agent（领队）头像更大、带角标
  - 右侧"添加智能体"（虚线框）和"批量添加"（闪电图标）

  Agent 详情表单（主区域）：
  - 基本信息：显示名称、英文标识、简介、职位名称
  - 模型与工具：模型选择下拉、工具权限开关（搜索/阅读/飞书/代码/文件/图像/HTTP/语音 等 10+ 个按钮）、自定义工具输入
  - 技能配置：已启用技能卡片列表 + "添加"按钮（打开技能模态弹窗）
  - 护栏规则：左右分栏 — 允许规则（绿色）/ 禁止规则（红色），TagInput 输入
  - 人格配置：文档标签页（SOUL/IDENTITY/AGENTS/USER/MEMORY/HEARTBEAT/TOOLS），每个对应一个 .md 文件编辑器

  Toolbar（Agent 详情顶部）：
  - Agent 名称 + 领队标记 + 未保存标记
  - 操作按钮：一键生成（AI）、测试对话、设为领队、编辑、取消、保存、删除

  模态弹窗：
  - AI 一键生成：输入角色描述，AI 自动填充 Agent 配置
  - 批量添加：多行输入，每行一个角色，批量 AI 生成
  - 技能库：搜索技能（本地已安装 + ClawHub 远程），选择启用
  - 测试对话：右侧滑出对话抽屉，用当前 SOUL 测试 Agent
  - 删除确认：领队删除有额外警告

  交互：
  - 点击顶部 Agent 头像切换选中
  - 编辑模式下所有字段变为可编辑输入
  - "一键生成"AI 自动填充
  - 技能弹窗支持搜索和远程安装
  - 拖拽排序 Agent（拖拽调整顺序）

  ---
  9. 渠道端管理 (Bindings) — 公司空间

  作用：配置飞书渠道和群组绑定规则（哪个群组由哪个 Agent 响应）。

  布局：左右分栏（左侧配置 + 右侧详情）

  左侧：
  - 渠道配置卡片：连接状态（绿点/灰字）、App ID（掩码）、App Secret（掩码）、测试连接按钮
  - 飞书群组列表：每个群组行显示群组名、绑定状态、关联 Agent

  右侧详情面板（点击群组后展开）：
  - 群组名称、群组 ID（oc_xxx...）
  - 类型：群组/私聊
  - 关联智能体下拉选择
  - 触发模式：@机器人触发 / 所有消息
  - 启用/禁用开关

  交互：
  - "重新配置"切换编辑渠道凭证
  - 点击群组行打开详情面板
  - 添加群组打开空白表单

  ---
  10. 一键部署 (Deploy) — 公司空间

  作用：将公司配置部署到目标办公室（服务器）。

  部署配置表单：
  - 选择子公司（下拉，所有公司）
  - 选择办公室（下拉，仅空闲办公室，显示 ✅/⚠️ 状态）

  部署进度（部署中显示）：
  - 进度条
  - 4 步骤卡片网格：准备配置 → 写入目录 → 重启进程 → 健康检查
  - 每步显示状态图标（待处理/运行中/完成/失败）

  运行中的公司：
  - 列表显示已部署公司 + 办公室 + 重新部署/卸载按钮

  最近部署记录：
  - 部署历史列表：状态标签、公司名、办公室名、相对时间

  交互：
  - 选择公司和办公室后点击"立即部署"
  - 部署中实时轮询进度
  - 可取消进行中部署

  ---
  四、关键交互模式

  1. 编辑模式切换：多数页面采用 查看/编辑 切换模式，编辑时出现"保存/取消"按钮
  2. 列表-详情联动：Providers、Office、Bindings 采用左侧列表选中 → 右侧详情展示
  3. 模态弹窗：创建表单、AI 生成、技能选择、删除确认等使用模态弹窗
  4. 实时反馈：部署进度、安装日志、连接测试均有实时状态展示
  5. 公司空间上下文：进入公司后侧边栏切换，所有 Agent/Bindings/Deploy 操作绑定到当前公司
